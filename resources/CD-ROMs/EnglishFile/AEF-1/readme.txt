1. Minimum system requirements

PC
- Pentium(r) II 
- 400 MHz processor
- Microsoft(r) Windows(r) 2000, XP, Vista
- 64 MB RAM
- 50 MB free hard-disk space
- 24x CD-ROM drive speed
- 800 x 600 screen resolution displaying 16-bit color
- Sound Blaster compatible sound card
- Mouse
- Headphones or speakers

Mac(r)
- G3 
- 400 MHz processor
- Mac OS(r) X.2, X.3, X.4
- 64 MB RAM
- 50 MB free hard-disk space
- 800 x 600 screen resolution displaying 16-bit color
- Mouse
- Headphones or speakers

2. Running the application

For PC
Set your keyboard to US English.
Ensure that no other applications are running.
Insert the American English File 1 MultiROM into your CD-ROM drive.
The MultiROM should auto-run.
If it does not auto-run, do the following:
- From the Start menu, choose Start and then Run.
- Type D:\Start.exe (where D is the letter of your CD-ROM drive).
- Click the OK button.
- The application should now start.

For Mac
Set your keyboard to US English.
Ensure that no other applications are running.
Insert the American English File 1 MultiROM into your CD-ROM drive.
Double click on the AEF 1 MR CD-ROM icon on your desktop.
Locate the program file named Start and double click.
The application should now start.

3. Playing the enhanced audio

On your computer:
Insert the American English File 1 MultiROM into your CD-ROM drive.
Open your computer's audio player and choose the CD-ROM drive.

On a CD player:
Put the CD into a standard stereo CD player. The CD will play in the same way as a normal audio CD.

Please note that the enhanced audio may not be compatible with some older, economy CD players.

4. Video playback

The video clips in the American English File 1 MultiROM will achieve optimum playback quality on computers at the upper end of the system requirements. Please note that if your computer has the minimum processor speed and memory, the playback quality may be inferior.

5. Technical support

If you experience any problems while running the American English File 1 MultiROM, and you have checked that your system and settings meet or exceed the minimum specifications, please email: elt.cdsupport.uk@oup.com
Please include details of:
-  platform (e.g. Windows 98, Mac OS X)
-  processor speed and size of RAM (e.g. Pentium II with 64 MB RAM)
-  a full description of the problem, including any error message(s)
-  the country you are e-mailing from

Please note that these support details are for the American English File 1 MultiROM only.  We will not be able to assist you with any problems encountered when running any software that is not included on this Multi-ROM.
